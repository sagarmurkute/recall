# Recall — Product Vision & Philosophy

> **"You already encountered the information. Recall helps you find it again."**

---

## 1. Product Identity & Definition
**Recall is an AI-powered personal digital memory system.** It is not merely a document search engine; it is an associative cognitive index that helps users retrieve information they have previously encountered across any medium:

* Course PDFs, syllabi, assignment rubrics
* Screenshots, whiteboard photos, diagrams
* Visited websites, documentation, and browser tabs
* YouTube videos and tutorial timestamps
* Social media reels, posts, and threads
* Desktop applications, code editors, and local files
* Notes, messages, and saved links

### The Fundamental Question Recall Answers:
> **"I remember seeing this somewhere. Where was it?"**

---

## 2. Core Product Principles

### Principle 1: Dual-Memory Architecture
Recall organizes human digital recall into two complementary tiers:
1. **Explicit Memory:** Artifacts the user intentionally uploads or saves (PDFs, screenshots, notes, docs).
2. **Contextual Memory:** Ambient activity breadcrumbs observed locally through **TRACE** (`Trace.exe` — Windows app focus, browser tabs, opened documents).

Unified Recall blends Explicit + Contextual memory to resolve queries across **Content**, **Context**, **Source**, and **Time**.

### Principle 2: Grounded Truth Over Conversational Filler
Recall is not a generic chatbot. Answers are grounded in the user's actual encountered data pool, accompanied by exact evidence (document page, window title, or URL).

### Principle 3: Zero Organizational Tax
Recall eliminates the burden of manual folder organization or note tagging. Users simply drop files or work normally; ambient indexing makes everything queryable.

### Principle 4: Transparent User Privacy & Agency
Contextual memory collection is local-first, pausable at any time, auditable, and selective. Users maintain absolute control over what is recorded and what synchronizes to the cloud.

---

## 3. Why Recall Must Exist

| Vector | Traditional Search | Generic AI Chatbots | Recall (Unified Memory) |
| :--- | :--- | :--- | :--- |
| **Search Scope** | Local file paths or exact browser history keywords | Generalized web training data (no private context) | Unified: Explicit documents + Contextual window/browser activity |
| **Query Style** | Exact keyword matching | Conversational, often hallucinated | Grounded natural-language retrieval with exact source evidence |
| **Multi-Modal** | Text only; blind to screenshots | Multi-modal only if manually uploaded each time | Ambient OCR on screenshots + parsed PDFs + browser URLs |
